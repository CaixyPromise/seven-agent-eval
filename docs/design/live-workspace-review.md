# 持续评分工作台：原型与实现复核

## Copy gate（实现前）

| 用户事实 | 承载位置 | 生命周期 | 文案/动作 |
| --- | --- | --- | --- |
| 事件仅在接收并持久化后才可观察 | 空状态、接收量 | 首次进入到第一条 ACK | “等待第一批生产事件” / 说明不会触发业务请求 |
| 覆盖率不等于业务正确率 | KPI 标题旁提示 | 每次查看窗口 | “评分覆盖率” + 信息提示 |
| 暂停不丢事件 | 顶部状态条与主操作 | 已暂停期间 | “评分已暂停，接收与持久化仍在继续” / 恢复评分 |
| 迟到证据可以修订尚未封板窗口 | 窗口状态与 Drawer | 水位线前 | “窗口仍可能因迟到证据修订” |
| 导出的快照可以带走 | Drawer 与窗口表 | 窗口可查询时 | “导出窗口” |
| 原始上游响应不可在页面泄漏 | 局部错误区 | 请求失败时 | 仅显示稳定中文错误码映射与重试 |

## Before | After | Why

| Before | After | Why |
| --- | --- | --- |
| [蓝色工作台原型](live-workspace-prototype.png) 展示计划、KPI、四张趋势图和窗口表 | `#/live` 按相同顺序实现：计划/范围/控制、五个 KPI、四张图、精确窗口表、详情 Drawer | 首屏先回答“是否在持续评分、评分到哪里、是否积压”，再提供趋势和可审计的精确值。 |
| 原型以蓝色曲线和分层卡片建立阅读层级 | 实现沿用现有 Ant Design 蓝色令牌、现有侧栏和按钮系统，图表由 ECharts 模块化渲染 | 避免新页面看起来像独立产品，同时不为基础控件重复造轮子。 |
| 原型中趋势点可下钻 | 图表点与表格行都打开同一 Drawer；表格是图表的无障碍精确替代 | 图形用于发现变化，Drawer 和表格用于核对计数、版本、结论与异常样本。 |

## 实现后检查项

- 1536×1024、DPR 1：与原型使用相同信息顺序和主要区块；实际截图为 `output/playwright/live-desktop.png`（本地验收产物，避免提交二进制截图）。
- 390×844（等效于高缩放的窄 CSS 视口）：KPI 和图表退化为单列，窗口表横向滚动，长 ID 允许折行；截图为 `output/playwright/live-mobile.png`。
- 加载与空数据：有独立空状态；暂停：主按钮与状态条有对应文案；积压与迟到修订：由窗口 scope 和 Drawer 展示；未知错误：只显示审核过的安全文案；reduced-motion：ECharts 关闭动画且全局 CSS 关闭过渡。受控事件源的浏览器控制台为零错误。
