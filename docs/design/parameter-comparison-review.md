# T10 增量产品与文案复核

2026-09-28。沿用已有蓝色 Ant Design 工作台与报告布局，新增候选比较能力；不把当前效果图冒充新的整页原型或完整 1:1 验收。实现分为 ComparisonPanel、ComparisonChart、ComparisonSamples，复用共享 ECharts 生命周期和证据组件。

## Copy gate

| 用户事实 | 承载位置 | 生命周期与口径 |
|---|---|---|
| 多候选重新调用同一冻结案例 | 发现卡、报告标题、冻结数据折叠区 | 运行前说明实际调用，报告保存输入摘要；不是同一回答改变评测 K |
| 参数是否被目标确认 | 候选表、同案例 Drawer | 明确自报一致／不一致／未确认，不推断内部一定生效 |
| 两次请求失败且保留其余结果 | partial 状态及结论 | 15/15 是已处理数，不等于 15 次成功 |
| 单候选均值和配对差值是两个口径 | 指标表、图表说明 | 各自有效分母与双方交集分别展示，不直接相减非配对均值 |
| 没有足够证据 | 表格 `—`、样本状态 | 不变成 0；没有处理器统计也不补默认值 |
| 可以提供有证据的比较，但没有唯一最佳 | 调优依据 | 配对案例可下钻；不声称显著性、自动搜索或综合最优 |

## Before | After | Why

| Before | After | Why |
|---|---|---|
| 只有评测 K 曲线，缺少真实目标参数比较 | 新增候选 target_parameters，固定评测身份的候选曲线与配对表 | 区分评测 @K 和改变目标 top_k 后重新调用 |
| 所有指标直接铺开，引用缺失项遮住主要比较 | 默认显示质量、耗时与成本，保留“全部指标” | 首屏可理解且不隐藏完整证据 |
| 仅展示一个均值可能误导缺失分母比较 | 有效/计划案例、配对数、双方配对均值及差值独立列 | 反例单测证明不使用“非配对均值之差” |
| 只有跨候选汇总无法定位变化 | 同案例 Drawer 候选 Tabs、共同输入、实际回答、检索与参数回执 | normal 的 top-3 显示三条检索结果，mismatch 可核对请求/返回 |
| 运行中无统计可能被误读成处理器关闭 | 运行中提示完成后生成；完成后无输出才说明处理器未提供 | 状态和真实生命周期一致 |
| 比较卡可能撑宽窄屏 | 容器横向滚动、图表自适应、指标表精确数据替代 | 390×844 检查 body 宽度 390，主要动作保留 |
| 搬走报告可能依赖原目录或 Python | 浏览器下载再导入另一无 Python 的目录 | 全部 Run 数据规范化逐项一致，不只是 HTTP 200 |
